# 앱 (최상단)

**4 대 컴포넌트**:

1. **Activity**: 화면
   ```kotlin
   class DetailActivity : AppCompatActivity()
   ```

2. **Service**: 백그라운드 작업
   ```kotlin
   class MusicService : Service()
   ```

3. **BroadcastReceiver**: 이벤트 수신
   ```kotlin
   class BootReceiver : BroadcastReceiver()
   ```

4. **ContentProvider**: 데이터 공유
   ```kotlin
   class ContactsProvider : ContentProvider()
   ```
