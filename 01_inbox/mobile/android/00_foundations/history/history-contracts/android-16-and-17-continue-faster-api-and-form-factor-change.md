# Android 16과 17은 빠른 API release와 form factor 변화를 계속 밀고 있다

2026년 7월 31일 기준 Android Developers 문서는 Android 16(API 36)과 Android 17(API 37)을 노출한다. Android 16 문서에는 2025년에 두 번의 Android API release가 계획되었다는 맥락과 ART, notification, security, form factor 변화가 정리되어 있다.

Android 17은 large screen resizability/orientation 정책과 API 37 target 흐름을 더 밀어붙인다. 그래서 old history 문서가 Android 14까지만 다루면 현재 learning map으로는 부족하다.

이 노트는 최신 version feature를 길게 복사하지 않고, version history가 왜 계속 확인 대상인지와 어떤 정본을 봐야 하는지만 남긴다.
