# Layout Inspector

상위 노트: [android-profiling-tools](01_inbox/mobile/android/06_testing_performance/performance/android-profiling-tools.md)

UI 계층 구조 분석.

**사용법:**

1. Tools → Layout Inspector
2. 실행 중인 앱 선택
3. 3D 뷰로 레이어 확인
4. 속성 패널에서 각 View 의 속성 확인

**성능 팁:**

- 중첩 깊이 줄이기 (ConstraintLayout 사용)
- 불필요한 배경 제거
- ViewStub 으로 지연 로딩
