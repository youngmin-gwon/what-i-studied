# Deep Link 계약

Deep Link는 외부 URI를 앱 내부 목적지로 연결하는 장기 계약이다. Manifest 선언, 도메인 검증, 앱 내부 라우팅, 인증 후 back stack 복원을 분리해서 설계한다.
