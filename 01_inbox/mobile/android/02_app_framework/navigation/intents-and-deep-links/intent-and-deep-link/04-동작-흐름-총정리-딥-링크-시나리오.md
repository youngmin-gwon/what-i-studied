# 동작 흐름 총정리 (딥 링크 시나리오)

유저가 인터넷에서 `https://example.com/restaurants/3`이라는 링크를 클릭하면 아래의 과정이 진행됩니다:

```mermaid
sequenceDiagram
    participant User as 유저
    participant OS as 안드로이드 OS
    participant App as 우리 앱

    User->>OS: 1. 링크(https://example.com/restaurants/3) 클릭
    OS->>OS: 2. "이 주소 좀 보여줘!(VIEW)"라는<br/>인텐트(주문서) 발행
    OS->>OS: 3. 설치된 앱들의 안내판(인텐트 필터) 훑어봄
    Note right of OS: Action: VIEW ✅<br/>Category: BROWSABLE ✅<br/>Data: https://example.com/restaurants ✅
    OS->>App: 4. "딱 맞네!" → 앱 실행
    App->>User: 5. 해당 식당 화면 표시
```

> [!TIP]
> 이 매커니즘은 인텐트 필터를 등록하는 `AndroidManifest.xml`의 구조와 밀접하게 연결됩니다. 매니페스트 구조에 대한 상세 내용은 [[android-manifest]]를 참조하세요.
