# Android Deep Links

Android Deep Link 문서는 외부 URI가 앱 내부 destination으로 들어오는 계약을 정리한다. 핵심은 URI 수신, 검증, 인증 상태, back stack 구성, App Link verification을 분리하는 것이다.
