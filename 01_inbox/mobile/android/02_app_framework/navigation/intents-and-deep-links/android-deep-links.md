# Android Deep Links

Deep Link 문서는 외부 URI 를 앱 내부 목적지로 안전하게 바꾸는 계약의 허브다. App Link 검증, Dynamic App Links, 인증 후 이동, notification 진입, 테스트를 분리해서 읽는다.
