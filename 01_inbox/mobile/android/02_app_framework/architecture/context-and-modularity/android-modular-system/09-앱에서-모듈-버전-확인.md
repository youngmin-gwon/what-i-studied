# 앱에서 모듈 버전 확인

상위 노트: [android-modular-system](01_inbox/mobile/android/02_app_framework/architecture/context-and-modularity/android-modular-system.md)

```kotlin
fun getModuleVersion(moduleName: String): Long? {
    val packageManager = packageManager
    return try {
        val packageInfo = packageManager.getPackageInfo(
            moduleName,
            PackageManager.MATCH_APEX
        )
        packageInfo.longVersionCode
    } catch (e: PackageManager.NameNotFoundException) {
        null
    }
}

// 사용
val artVersion = getModuleVersion("com.android.runtime")
Log.d("APEX", "ART version: $artVersion")
```
