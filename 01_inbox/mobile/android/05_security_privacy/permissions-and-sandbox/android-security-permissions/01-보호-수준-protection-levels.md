# 🛡️ 보호 수준 (Protection Levels)

| 수준            | 설명                   | 승인 방식            |
| ------------- | -------------------- | ---------------- |
| **Normal**    | 낮은 위험 (인터넷, 진동 등)    | 설치 시 자동 승인       |
| **Dangerous** | 높은 위험 (위치, 카메라, 연락처) | **런타임 시 사용자 승인** |
| **Signature** | 동일한 서명의 앱끼리만 공유 가능   | 시스템 자동 승인        |
| **Internal**  | 시스템 내부 전용            | 일반 앱 접근 불가       |
