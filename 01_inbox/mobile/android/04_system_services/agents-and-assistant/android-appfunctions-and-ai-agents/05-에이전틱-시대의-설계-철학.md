# 🏛️ 에이전틱 시대의 설계 철학

이제 사용자는 "앱을 켜서 작업을 수행"하는 방식보다 "에이전트에게 결과물을 요구"하는 방식을 선호하게 된다.

>[!TIP] **Devil's Advocate : 앱의 UI 는 더 이상 유일한 진입점이 아니다**
>미래의 안드로이드 개발자는 화려한 UI 를 짜는 것보다, 에이전트가 내 앱의 기능을 얼마나 정확하고 빠르게 사용할 수 있게 만드는지(**Function-first mindset**)를 더 고민해야 한다. 앱의 가치가 화면 안(In-app)이 아닌 화면 밖(Cross-app)에서 결정되는 시대가 왔다.
