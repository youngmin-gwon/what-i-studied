# 📊 언제 무엇을 사용하는가?

| 분류 | 작업 특성 | 권장 API |
| :--- | :--- | :--- |
| **즉시 실행** | 짧은 작업 (수 초 이내) | Kotlin Coroutines (`viewModelScope`) |
| **즉시 실행 (길게)** | 지속적 작업 (음악, 운동) | **Foreground Service** |
| **지연 가능** | 보장된 실행 필요 (업로드, 동기화) | **WorkManager** |
| **정확한 타이밍** | 정해진 시각에 실행 | **AlarmManager** |
