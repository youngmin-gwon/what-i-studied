# 파티션 구조

### 물리 레이아웃

```
/dev/block/sda (UFS/eMMC)
├─ boot_a              # 커널 + ramdisk
├─ boot_b
├─ vendor_boot_a       # Vendor ramdisk
├─ vendor_boot_b
├─ super               # Dynamic partitions
│  ├─ system
│  ├─ system_ext
│  ├─ vendor
│  ├─ product
│  └─ odm
├─ userdata            # 사용자 데이터
├─ metadata            # 암호화 키
└─ misc                # Boot control
```

### Dynamic Partitions (super)

```bash
# 확인
adb shell lpdump

# 출력:
# system: 2048 MB
# vendor: 1024 MB
# ...
```

**이점**: 파티션 크기 동적 조정 (OTA 시)
