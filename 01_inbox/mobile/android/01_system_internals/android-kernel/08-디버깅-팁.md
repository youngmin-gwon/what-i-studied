# 디버깅 팁

상위 노트: [[android-kernel]]

### dmesg

```bash
adb shell dmesg | grep -i error
```

### Perfetto

실시간 트레이싱:

```bash
adb shell perfetto -c trace_config.pbtxt -o /data/misc/perfetto-traces/trace
adb pull /data/misc/perfetto-traces/trace
```
