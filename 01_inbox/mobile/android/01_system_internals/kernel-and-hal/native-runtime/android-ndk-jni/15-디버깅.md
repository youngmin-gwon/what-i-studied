# 디버깅

상위 노트: [android-ndk-jni](01_inbox/mobile/android/01_system_internals/kernel-and-hal/native-runtime/android-ndk-jni.md)

```bash
# NDK 빌드 로그
./gradlew assembleDebug --info

# Native 크래시 로그
adb logcat | grep "DEBUG"

# lldb 디버깅
# Android Studio → Run → Debug 'app' (C++ 브레이크포인트 설정 가능)

# 심볼 파일 확인
ls app/build/intermediates/cmake/debug/obj/arm64-v8a/
```
