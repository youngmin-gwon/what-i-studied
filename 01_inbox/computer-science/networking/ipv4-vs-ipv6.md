# IPv4 vs IPv6 (인터넷 프로토콜 주소 체계 비교)

## 1. 개요 (Overview)

인터넷 프로토콜 주소 체계는 32비트 기반의 레거시 주소 체계인 **IPv4 (Internet Protocol version 4)** 와 주소 고갈 문제를 해결하기 위해 등장한 128비트 차세대 주소 체계인 **IPv6 (Internet Protocol version 6)** 로 나뉜다.

---

### 초보자를 위한 쉽게 이해하는 비유

* **IPv4 (구형 4자리 전화번호)**:
  - `192.168.0.1` 처럼 숫자로 구성된 32비트 주소 체계. 주소 개수가 약 43억 개로 제한되어 전 세계 디바이스 증가로 **주소가 완전히 고갈**됨.
* **IPv6 (신형 16자리 주민등록번호 + 알파벳)**:
  - `2001:0db8:85a3::8a2e:0370:7334` 처럼 128비트 주소 체계. 주소 개수가 **전 지구의 모래알 개수보다 많아(약 $3.4 \times 10^{38}$ 개)** 주소 고갈 걱정이 0%.

---

## 2. IPv4 vs IPv6 핵심 기술 비교표

| 비교 항목 | IPv4 (Internet Protocol v4) | IPv6 (Internet Protocol v6) |
| :--- | :--- | :--- |
| **주소 비트 길이** | **32 비트 (4 바이트)** | **128 비트 (16 바이트)** |
| **표기 방식** | 10진수 4자리 (`192.168.1.1`) | 16진수 8자리 (`2001:db8::1`) |
| **주소 총 개수** | 약 43억 개 ($2^{32}$) | 약 $3.4 \times 10^{38}$ 개 ($2^{128}$) |
| **헤더 크기** | 가변 크기 (20~60 바이트) | **고정 크기 (40 바이트, 처리 속도 빠름)** |
| **IPSec 암호화** | 선택 사항 (Optional) | **기본 내장 필수 규격 (Mandatory)** |
| **주소 자동 할당** | DHCP 서버 필요 | **SLAAC (자체 주소 자동 생성 기능 지원)** |
